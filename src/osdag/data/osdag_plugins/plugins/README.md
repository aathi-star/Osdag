# Osdag Sample Plugin

sample plugin for the Osdag that demonstrates the plugin system functionality.

Once installed, the plugin will be automatically discovered by Osdag. You can activate it through the Plugins menu in Osdag.


Install it using
```bash
pip install -e .
```
after moving to the directory aathi-plugin

## Requirements

- Python >= 3.7
- PyQt5 >= 5.14.2
- Osdag
